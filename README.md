<p align="center"><sub><em>
I build systems where software, infrastructure, automation, and AI meet.<br />
My current work revolves around backend architecture, infrastructure orchestration, game-server systems, developer tooling, and AI-assisted engineering workflows.<br />
<br />
I care less about writing more code and more about designing systems that remain correct under failure, concurrency, scale, and change.<br />
That means explicit contracts, deterministic state transitions, strong ownership boundaries, reproducible infrastructure, and automation that removes unnecessary human work.<br />
<br />
Most of what I build is private, experimental, or still evolving.<br />
The goal is simple: build independent systems that compound capability without compounding operational noise.
</em></sub></p>

> *“Code is not just about making things work, but making them work well.”*
